ReloCalc — Complete Build Specification Prompt (v2)

Relocation Financial Feasibility Calculator with Recurring Bills & Obligations

1. APP IDENTITY

- Name: ReloCalc

- Tagline: "Know Before You Go"

- Purpose: Single-page HTML app that calculates whether a user can financially survive a relocation — factoring in income, one-time relocation costs, recurring monthly obligations (bills, loans, credit cards, subscriptions), living expenses at destination, and savings runway

- Theme: Google Material-inspired — #1A73E8 primary blue, #1A1A2E dark text, #F0F2F5 card backgrounds, white cards with subtle shadows, monospaced numbers, pill badges, capsule buttons

7. FEASIBILITY VERDICT

Calculation

totalMonthlyBurn = monthlyLivingExpenses + totalMonthlyObligations
monthlySurplus = netMonthly − totalMonthlyBurn
relocationCostsCoveredBySavings = currentSavings >= totalRelocationCosts
surplusRatio = monthlySurplus / netMonthly
obligationRatio = totalMonthlyObligations / netMonthly

12. TECHNICAL REQUIREMENTS

Stack

- Single HTML file, zero dependencies

- Vanilla CSS + JavaScript only

- No frameworks, no CDN, no build tools

- Works offline after first load

Responsive

- Mobile-first (375px minimum)

- Tablet (768px) — two-column layout

- Desktop (1024px+) — three-column layout

Accessibility

- All inputs labeled with <label> elements

- ARIA roles on dynamic content

- Keyboard navigable (tab order logical)

- Color is never the only indicator (always paired with text/emoji)

Performance

- All calculations run synchronously on input change

- No debounce needed — instant feedback

- Obligations list uses event delegation for efficiency

13. CALCULATION TRIGGER RULES

Every calculation must fire on ANY of these events:

- Any income field changes (wage, hours, days, tax, frequency)

- Any relocation cost item added, removed, or amount changed

- Any living expense item added, removed, or amount changed

- Any obligation added, removed, edited, or frequency changed

- Savings or savings goal changed

- Currency or exchange rate changed

Trigger Method

- Single recalcAll() function called by every input's oninput / onchange event

- Obligations section calls recalcAll() after any add/edit/delete operation

- recalcAll() reads all DOM values, computes everything, updates all output displays
